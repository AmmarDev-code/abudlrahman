وثيقة متطلبات نظام المتجر المحاسبي (PRD)

ملخص معمارية المشروع مفتوح المصدر

نظام متجر إلكتروني وقنوات بيع متعددة مربوط بحلقات متزامنة مع قيود اليومية ومستودعات المخزون بدقة مصرفية ACID.

1. الوحدات البرمجية الأساسية (Core Modules):

  • وحدة المبيعات ونقاط البيع (POS & Storefront): سلة شراء سريعة، قارئ باركود، فواتير ضريبية، وطباعة إيصالات حرارية.
  • وحدة إدارة المخزون (Multi-Warehouse Inventory): تتبع دقيق للأرصدة، تنبيهات حد الطلب، وإدارة تواريخ الصلاحية ورقم الوجبة.
  • محرك الحسابات الآلي (Automated Ledger Engine): توليد تلقائي للقيود (مدين/دائن) مع كل فاتورة أو مرتجع دون تدخل يدوي.
  • لوحة تحكم الإدارة المالية (Executive CFO Dashboard): ميزان المراجعة، قائمة الأرباح والخسائر، وحركة الخزينة اللحظية.

2. هيكلية قاعدة البيانات العلائقية (Relational SQL Schema):

• accounts (id, code, name, type [asset, liability, equity, revenue, expense], balance)
• journal_entries (id, date, reference_type, reference_id, notes, status)
• journal_lines (id, entry_id, account_id, debit, credit, description)
• products (id, sku, barcode, cost_price, selling_price, stock_qty)
• orders & order_items (id, customer_id, total_amount, payment_status, created_at)

3. الأمان وتوافق الأنظمة:

المشروع يدعم النشر السحابي عبر Docker، مع توفير واجهات RESTful APIs موثقة بـ Swagger لسهولة ربطه بتطبيقات Flutter أو أي منصات خارجية.
